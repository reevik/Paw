    Models

      Provider

        Paw looks where other tools keep an Anthropic key: your login shell, Claude Code, opencode. It reads the key from there when a session starts and never copies it.

        How it works

        Paw Agent runs inside Paw: it reads, searches and edits files in the tab's folder and runs commands there, asking first as the tab's approval level says (/approval). Ollama models need tool support (ollama show <model> lists “tools”); the list above only shows those. A model written anthropic/… or ollama/… uses that provider.

        Command

        Placeholders: {bin} {prompt} {model} {permission} {session}. Wrap optional parts in [[ … ]] — they're dropped when a placeholder inside is empty.

        Approval levels

        What {permission} becomes for each of Paw's levels (/approval). Leave a level empty if this agent can't express it.

        Added at launch for each action you approve on an approval card; {rule} is the action. Empty: approval cards can't allow single actions for this agent.

        How this agent gets the skills from the External folders in the sidebar. With a flag, {skills} is a plugin folder Paw keeps up to date. Without one, Paw tells the agent about them in the conversation: a list it can read from, or — for agents that can't open files — the instructions themselves.

        A new tab always starts a new conversation. Follow-up prompts and restarts continue it.

        Found in the agent's output after each run; used as {session} for the next prompt and after a restart.
